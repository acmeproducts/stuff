# Observation dates and compact inspection

Daily provider bar timestamps differed within the same observation date: DXY/WTI/copper at 04:00 UTC, VIX at 07:00, equity ETFs including IWM at 13:30, while governed evaluations were at midnight. The renderer used those provider hours as X positions. Consequently daily October 16 points appeared to end at different positions despite having the same observation date.

The shared source adapter now plots non-intraday observations at midnight of their UTC observation date. Each point retains the exact original provider timestamp in `sourceT` and the exact value in `raw`; normalization/reference arithmetic remains unchanged. Actual earlier observation dates remain earlier. Intraday/hour/minute sources keep their time coordinates. Requested viewport bounds remain unchanged. Existing captured Library evidence remains captured; new snapshots record the corrected plotting coordinates and original provenance.

The owner's subsequent crosshair instruction replaces the longer inspection prose with three fields: linked observation date | index value | native value. Dollar-denominated values receive `$`; other native measures retain their units, and a governed index has no underlying dollar quote (`—`). The linked date opens the catalog source, or the model evidence for a derived index. The close button and existing inspection/dismissal gestures remain. Reference/cadence/provenance remain in source metadata and chart snapshots; the reference regression checks now assert the actual date/value and stored normalization instead of requiring prose the owner explicitly removed.

The added date suite compares every rendered real point against source values/timestamps across all catalog sources, seven horizons, both consumers and desktop/phone Chrome/Edge. Focused cases compare October 16 X coordinates across DXY, IWM, SPY, VIX, QQQ, WTI, copper and GRW under Fixed/Horizon and Indexed/Y1+Y2; retain actual earlier endpoints; exercise the compact fields, actionable source link, close control and retained inspection after rerender. An isolated real-adapter test protects distinct intraday times. Existing reference/Data, selector/config and chart-state gates remain required before isolated validation publication.
