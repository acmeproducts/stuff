How this version works

Market Navigator no longer builds history in the browser. The database is collected and derived first. The UI only reads persisted series and indexes.

Regime is the persisted rollup of Risk + Growth + Macro. Each category index is persisted from its declared component series. The number shown as current is always the final plotted point.

Index changes are shown in points. Component changes are shown as percent change from the selected-period starting value.
