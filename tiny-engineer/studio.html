Connect the robot to home Wi-Fi
  1. Power the assembled robot through its main USB-C port. If it already shows a home-network IP, put your phone on that same home network and enter the IP above.
  2. For first setup, open Settings → Connections → Wi-Fi on your Samsung. Join TinyEngineer-XXXX and stay connected if Android reports no internet.
  3. While joined to the robot, open the robot’s Wi-Fi setup. Keep the builder’s calibration. At Connection or Network, choose Wi-Fi and enter your 2.4 GHz home Wi-Fi name and password. Note the numeric address shown when it connects.
  4. Return your phone to your normal home Wi-Fi. Power-cycle the robot if the wizard requests it. Enter its home-network address above and tap Connect. If no setup network appears, check your router’s connected devices for the robot’s IP.

Test bench

First test and firmware updates
  1. Plug the assembled robot into USB-C power. Check that the robot and phone are on the same 2.4 GHz Wi-Fi or hotspot.
  2. Enter its Wi-Fi address above, tap Connect, and allow local network access in Chrome. Try the numeric IP from setup if the name fails.
  3. Choose Bell strike and tap Run test. Watch the right hand and listen for one ding. Then try Reading and Stop / idle.

Firmware is the program stored inside the robot. A tested, pre-flashed unit can run stock gestures immediately. Joining Wi-Fi and saving routines are separate from updating firmware.

For a needed update, have the builder confirm the release for your exact assembly and record its calibration. Plug a USB-C data cable into the main control board, open the official installer in a supported Chrome or Edge browser, select the release, tap Connect & install, choose the USB device, and keep power connected until it finishes. Use the installer’s normal update and preserve settings if offered. Have the builder handle any required erase or recalibration. After restart, reconnect and test Bell. Builder’s instructions
