## Architecture (pinned)
- **Coordinates:** Web Mercator tile math; base terrain at zoom 15 (~1.2 km tiles at equator); lat/lon ↔ tile/pixel conversions in-app; horizontal meters locally scaled by cos(latitude) so horizontal and vertical units match.
- **Elevation:** Terrarium PNG tiles from the public elevation-tiles-prod S3 endpoint (`/terrarium/{z}/{x}/{y}.PNG`, CORS-enabled). Decode: `h = R*256 + G + B/256 − 32768` meters. Fallback: seeded fBm noise heightfield (globally continuous across tiles) so terrain always renders (HUD flags SRC: PROC); tiles built instantly from fallback upgrade in place when real elevation arrives; retry on tile re-entry after unload. Fetch hardening (M3.1): alternate-host fallback chain, 12 s timeout, 6-way concurrency cap, wrapped/clamped tile coordinates, failures reported as a quiet HUD NET-fail counter (no error-box spam). M7.1: each quiet failure also appends one line to the exportable log.
- **Imagery (M3.3):** Esri World Imagery z15 tiles matched 1:1 to terrain tiles (`server.arcgisonline.com` primary; `services.arcgisonline.com` mirror as fallback host), fetched as blob with the same 12 s timeout / concurrency queue as elevation, decoded via Image → Babylon DynamicTexture (or direct objectURL texture), applied to the tile's own StandardMaterial clone with `diffuseTexture`; vertex colors kept as fallback when the image fails (HUD IMG: OK n / PROC n) and as the imagery-OFF mode. Texture sampling: bilinear, anisotropic filtering where available; material specular stays black, ambient lifted so shaded slopes stay readable. Attribution string "Imagery © Esri & contributors" on HUD (made visible in M4).
- **Sky & lighting (M3.3):** replace flat-emissive skybox with a vertical-gradient sky (procedural gradient texture on the sky sphere/box: zenith → horizon, day/night aware, still driven by the time-of-day slider); sun gets a warm tint near horizon, hemisphere ground color darkened for contrast; fog color matched to horizon color so terrain fades naturally instead of cutting to solid blue.
- **Mobile navigation (M3.4):** pointer-role state machine on canvas touch pointers — first left-half touch claims the floating move stick (base at touch point, knob follows, vector normalized to ≤1); any other touch is a look finger (one) or a pinch pair (two, existing FOV-zoom math reused); per frame the stick vector displaces the camera (engine delta time × mode top speed × magnitude; walk = heading projected to ground, fly = full forward vector); JUMP sets vertical velocity, gravity integrates each frame, landing clamps to worldHeight + eyeHeight and the walk-mode ground snap is skipped while airborne; UniversalCamera keyboard/mouse inputs untouched for desktop; Babylon's built-in touch camera input removed; JUMP + stick elements sit below the gear/modal z-index and hide while the modal is open.
- **Land cover / biomes (M4):** PRIMARY — Copernicus LCFM LCM-10 V1 classification windows via Terrascope public TiTiler (nearest-neighbour, class codes → ocean/beach/grass/forest/rock/snow/desert/cropland/urban), driving vegetation scatter and (imagery-off/failed) vertex colors. STAC collection: `https://stac.terrascope.be/collections/lcfm-lcm-10`; coverage 60 S–83 N (outside → fallback). TiTiler base pinned as `https://titiler.terrascope.be`; tile template (primary): `/cog/tiles/WebMercatorQuad/{z}/{x}/{y}@1x.png?url={assetCogHref}&resampling=nearest`; fallback pattern: `/stac/tiles/WebMercatorQuad/{z}/{x}/{y}@1x.png?collection=lcfm-lcm-10&item={itemId}&assets={assetId}&resampling=nearest`; asset/item href discovered at runtime via the STAC collection endpoint, then cached. Circuit breaker: after N consecutive failures the LC fetch chain disables itself (HUD shows LC: PROC) so a dead endpoint is never hammered; procedural biomes stay live. Any fetch/decode/coverage failure → FALLBACK — per-vertex procedural classification from latitude, elevation, moisture noise; bare-ground color when class unknown. Biome classification stored per tile (256×256 class grid) so vertex colors, scatter, and water placement all read the same source; procedural→TiTiler upgrade rebuilds the tile mesh and rescatter in place. **STATUS: landed, confirmed in artifact 2026-09-30.**
- **Water (M4):** sea-level (0 m) animated water plane per terrain tile (semi-transparent blue, specular highlight, gentle vertex/alpha wave animation via render loop); renders on every tile so coastlines, bays, and lakes read immediately; never blocks terrain. **STATUS: landed (single player-following plane covering the ring), confirmed 2026-09-30.**

## Risk register
- CDN blocked → try 3 CDNs in order; verify the BABYLON global after each script load; if all fail, show on-screen fatal error (never silent).
- Terrarium 404/429/CORS → per-tile fBm fallback; HUD flags PROC; retry on tile re-entry; failures counted quietly on HUD, not spammed. M7.1: quiet failures also land in the exportable log so the owner can share them as text.
- Esri imagery unavailable/slow/CORS-blocked → per-tile fallback to vertex-color appearance (terrain still renders), HUD IMG PROC count, mirror host retry, never blocks elevation or streaming; imagery OFF toggle always available.
- Imagery attribution requirement → HUD credit line "Imagery © Esri & contributors" always visible while imagery layer is on (ships visibly in M4).
- TiTiler unavailable/slow/out-of-coverage (60 S–83 N) → per-tile procedural biome classification; HUD flags PROC; land cover never blocks terrain render; circuit breaker stops repeated hammering of a dead endpoint.
- Overpass rate-limit → exponential backoff, in-memory cache, procedural grid fallback; HUD flags. M5 adds: 25 s query timeout, debounce so walking never fires a query storm, circuit breaker so a dead Overpass never blocks city fallback.
- Overpass bbox too large / dense city → cap bbox to ring extent (~2.5 km), `out geom` with way limit, chunk way processing across frames, merged meshes to bound draw calls; worst case falls back to procedural city for that area.
- Road ribbons on steep terrain → drape by sampling worldHeight per node with a small +0.15 m lift; segments subdivided when long so hills don't cut through ribbons.
- City meshes vs teleport → all city meshes are owned by an area container disposed in teleport() alongside tiles; rebuilds fire after the ring settles at the new origin.
- Phone perf → quality presets (LOW/MED/HIGH, shipped in M3.2) scale subdivisions, ring radius, vegetation density, particles; M3.3 adds ~25 texture decodes per ring rebuild — decoded through the existing 6-way queue so streaming never stalls; if decode cost hurts on LOW, drop imagery resolution via canvas downscale. M4 vegetation uses thin instances (one draw call per species per tile) so scatter stays cheap on phones. M5 keeps city geometry merged per area chunk (≤ a handful of extra draw calls) and skips building extrusion on LOW beyond the center area. M6 clouds are a handful of alpha billboards and rain one particle system; LOW preset reduces particle/cloud counts.
- Build-env fetch failures → irrelevant at runtime; app validates services live in the browser and reports on HUD.
- Owner cannot tell which build is loaded → BUILD tag stamped on HUD every build.
- Owner cannot tell whether console errors remain → on-screen error box traps every window.onerror and unhandledrejection; empty box = clean console. M7.1 strengthens this: all trapped errors and quiet failures accumulate in an exportable text log (COPY/SAVE) so diagnosis no longer depends on screenshots.
- Owner cannot paste screenshots into this text channel → M7.1 log export is the workaround: the app renders its own diagnostics as copyable/downloadable text. **Proven 2026-10-02: the owner pasted the exported log and it identified the M7.2 crash exactly — ask for the log first on any future problem report.**
- Static artifact verification cannot catch runtime API mismatches → M7.1b proved this: `BABYLON.Quaternion.RotationYaw` never existed, passed every static check, and killed every run since M4. Mitigations: (1) the exportable log is the primary diagnosis channel; (2) new Babylon API usages get guarded/failure-isolated paths by default (M7.2 rule); (3) smoke-test acceptance checks always include "app starts to the render loop with no red error box" so a dead-on-arrival build can never be called verified.
- Cosmetic subsystem crash (vegetation, future overlays) → M7.2 rule: wrap in try/catch, log one line, degrade to rendering without the cosmetic layer — never abort startApp, streaming, or the render loop.
- Clipboard API unavailable (insecure context / old browser) → COPY falls back to a temporary textarea + document.execCommand('select-all') so the text is at least selectable; SAVE via Blob+anchor download works everywhere; both wrapped in try/catch and report their result on the button label.
- M7.1 log spam from repeated per-tile failures → ring buffer caps at ~400 lines and identical consecutive lines are coalesced with an ×n suffix so one dead service cannot flush the buffer (coalescing finalized in M7.1b).
- Log panel hidden behind the settings modal or sticks → M7.1b raises the panel z-order above the settings modal and hides sticks/jump while it is open, so the owner can always reach COPY/SAVE.

- Jump-to-location far from origin → floating-point drift / stale tiles; mitigated by full re-origin teleport (recompute origin tile, dispose all tiles, rebuild ring, respawn) rather than raw camera move. M5 city meshes join the same dispose/rebuild path. M7 save/load restores position through the same teleport path, so a restored spawn is drift-free anywhere in the world.

- Pinch conflicts with Babylon touch camera input → pinch zoom implemented on raw pointer events; Babylon touch input for camera rotation limited to single-pointer drags. M3.4 goes further: Babylon's built-in touch camera input is removed entirely and all touch is routed through our pointer-role state machine (stick / look / pinch), eliminating double-rotation.

- Credentials in chat → never persist tokens in plan, code, or persisted thread state; scrub/reset any that leak into persisted history before pushing (see SECURITY INCIDENT); treat exposed tokens as compromised.
