# Modular NOW + Analyze (dumb front end)
Reads only pre-built packages in store/ (from ../model-batch-store). No date math, no rebasing, no filtering in the page.
Modules in the one file: MNStore (loads packages), MNChart (draws arrays on equal batch slots, Y1 + Y2), ChartPanel (header, legend, chart, controls bound to a state bus), app wiring (NOW and Analyze are two ChartPanels; Analyze starts as a clone of NOW's state and keeps its own horizon). A dashboard of small multiples = many ChartPanels (or bare Charts) on one shared bus, so one horizon / Fixed-vs-Horizon / dual-axis setting governs all of them.
Rules built in: chart taps never open the card; long-press (or right-click) a legend chip opens the card with the Analyze icon; a tap only focuses; a series with too few readings for the horizon is greyed, disabled and not drawn; dollar series group on Y2 in Dual axis.
Lab result (Sep 22 data): 5D shows 5 equal batch slots (Sep 16,17,18,21,22), every line ends at the right edge, NFCI greyed; Fixed and Dual axis both change the chart; add series works; Analyze opens, has its own horizon, and closing it leaves NOW unchanged. Not verified: real phone, GRW/MAC visuals, 1D look.
