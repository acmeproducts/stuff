How to read this

This is a windshield, not a trading terminal. Regime is the parent. Risk, Growth and Macro are its child indexes. Each index is built from its component series. The same hierarchy is used for calculation, charting and navigation.

Index change is expressed in points. Components are rebased to 0% for the selected horizon while retaining their actual start and end values. Current always means the final plotted database observation.
