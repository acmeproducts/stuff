Date: 2026-09-07

`/home/support/.openclaw/workspace/https/report/SOT/archive/20260907-001651-turn01-r12-ssot-virtual-volume-release`

- record version 6, filename and SHA-256 checksum in `schema_migrations` using the same managed-migration contract as prior releases;
