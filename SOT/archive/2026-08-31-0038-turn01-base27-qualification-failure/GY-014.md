# GY-014 — AI Configuration replacement deleted protected storage defaults

## Rejected approach

Replacing the complete governed `openConfig()` function to add AI provider controls.

## Failure

The replacement removed the existing `Default Target` and `Default Backup` controls. Base-27 therefore failed mechanical qualification with `DEFAULT_TARGET missing` before cutover.

## Permanent rule

New feature integration into a governed composite surface must preserve every protected capability already owned by that surface. For SOT Configuration, operational AI must coexist with storage defaults; adding AI may not replace or bypass Default Target / Default Backup configuration.

A candidate missing any protected Configuration capability is rejected before cutover and its generated HTML is not a valid implementation ancestor.
