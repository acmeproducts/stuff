# GY-015 — Partial nounset fix left the same dependent-local defect in browser harness

## Rejected approach

Correcting only the first observed Bash `set -u` failure in `parse_scripts()` without auditing the qualifier for the same declaration pattern elsewhere.

## Failure

Base-29 passed all generated static and JavaScript parse gates and exact probe identity, then failed before browser execution:

`tag: unbound variable`

The same defect existed in `run_browser()`:

`local url="$1" tag="$2" dump="$QUAL_DIR/browser-$tag.dom" ...`

Under `set -u`, expansions later in the same `local` command can occur before the earlier assignment is available.

## Permanent rule

When a shell-language failure is root-caused to a structural pattern, the entire candidate installer must be audited for that pattern before the next handoff. Do not fix only the first occurrence.

For positional/dependent Bash locals under nounset, declare independent inputs first, then dependent variables on subsequent commands.
