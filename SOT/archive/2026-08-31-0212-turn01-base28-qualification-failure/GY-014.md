# GY-014 — Same-command dependent Bash locals under `set -u`

## Rejected pattern

Declaring a local variable and using it to initialize another local variable in the same Bash `local` command while nounset mode is active.

Rejected example:

```bash
local html="$1" tag="$2" dir="$TMP/scripts-$tag"
```

This can abort before qualification logic runs because expansion occurs before the local assignment becomes available.

## Permanent rule

Under `set -u`, any local variable referenced by another initializer must be established in a prior command. Qualifier shell mechanics are part of release quality and must not block the actual parser/browser gates with preventable shell errors.
