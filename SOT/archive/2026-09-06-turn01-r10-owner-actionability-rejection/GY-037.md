# GY-037 — R10 owner rejection: analytics without an operating path

Date: 2026-09-06

R10 mechanically qualified and correctly exposed deterministic storage intelligence, duplicate evidence, project storage setup, and AI configuration. Owner browser review rejected the Dashboard presentation because the main surface remained an analytics report rather than a safe-cleanup operating surface.

Observed defects:

- Recommendation banners such as protection and duplicate findings were informational and did not expose an explicit next action.
- The global duplicate list expanded unbounded on the Dashboard and consumed most of the page.
- The top storage-estate bars required the owner to infer what the numbers meant and did not show a clear quantified journey from in-scope content to safe/certified content and remaining work.
- Project rows showed state but did not make the one valid next action explicit.
- Selecting a project permanently expanded a large detail section beneath the project table, duplicating information and forcing unnecessary scrolling.
- An unscanned project rendered zero-valued duplicate/protection analytics even though no committed scan evidence existed.

Owner outcome is the governing product objective:

**Safely clean up files, prove required independent copies, certify the cleaned estate, then cold-store or deliberately retire the original source media.**

Required correction:

- action-first recommendation controls;
- one global cleanup/protection progress visualization: `IN SCOPE → SAFE / CERTIFIED → REMAINING → NEXT ACTION`;
- compact project rows with explicit next action;
- project detail in a deliberate modal/drill-down;
- global duplicate evidence collapsed by default and bounded/scrollable when expanded;
- no cleanup/protection analytics for an unscanned project;
- retain Database/Activity/Settings/Deep Dive as supporting evidence surfaces rather than Dashboard clutter.

R10 remains the mechanically qualified implementation lineage. R11 must be a clean UI-only source advance from the governed R10 build path; do not patch the installed/generated R10 HTML.
