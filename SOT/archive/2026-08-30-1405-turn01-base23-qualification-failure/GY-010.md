# GY-010 — Whole-function owner-gate replacement that erases protected completed-state behavior

**Status:** REJECTED
**Evidence:** Turn 01 Base-23 mechanical qualification
**Decision date:** 2026-08-30

## Rejected approach

Correct a UI defect by replacing an entire workflow renderer without explicitly preserving all protected branches already established by the prior clean integration.

Base-23 replaced `renderIndex` to stop completed-state flashing and improve active-state refresh. That replacement omitted Base-22's completed-state duplicate findings branch.

## Why rejected

The new correction passed its own targeted checks while silently deleting an earlier required capability: immediate `2-copy`, `3-copy`, and `4+ copy` duplicate summaries and drill-down after fingerprint completion.

A correction is not valid if it fixes the new owner gate by reducing the previously governed behavioral contract.

## Required replacement

The next clean Base must merge behavior rather than overwrite it:

- active Index: silent non-destructive refresh;
- completed Index: stable, no polling rerender;
- completed Index must still render duplicate cardinality and drill-down;
- qualification must test both active and completed branches in the same generated function.

Base-23 remains failed pre-cutover evidence only and is not an implementation ancestor.
