## R25 is permanently rejected as an implementation ancestor
R25 became a runtime patch stack over R11. Even when an individual patch appeared visually correct, subsequent patches repeatedly restored old filters, regressed tiles, duplicated AI controls, and split Library persistence across competing state machines.

Permanent veto:
- no iframe release;
- no runtime baseline fetch;
- no sidecar patch-stack release;
- no DOM monkey-patch release;
- no second filter or persistence state machine;
- no patching a rejected candidate forward.

## Clean-build rule
The next release is produced by taking a known clean standalone source and applying one reviewable ordinary source diff. R21 wrapper code itself is never inherited; only accepted behavior is transplanted directly into the standalone source.
